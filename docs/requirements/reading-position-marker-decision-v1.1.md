# Reading Position Marker Decision v1.1

**Status:** Approved  
**Date:** 7 September 2026  
**Supersedes:** Resume Reading Decision v1.0

## Phase 1 Decision
The user manually selects one Quran verse as their current reading position using a simple visual marker.

## User Flow
1. User reads Quran.
2. User wants to stop.
3. User taps the marker/bookmark control on the relevant Ayah.
4. The application saves the Surah and Ayah locally.
5. When the user returns, the application displays a Continue Reading / Resume option.
6. The saved Ayah remains visually marked in the Quran reading screen.

## Requirements
- One manually saved reading position in Phase 1
- User controls where the position is marked
- Saved locally and fully offline
- No login or account
- Continue Reading / Resume card or prompt when returning
- Visual marker beside the saved Ayah
- Resume opens the exact marked position

## Audio
Audio resume behaviour will be specified separately during Functional Requirements. The approved reading-position marker applies specifically to Quran reading.

Multiple bookmarks are deferred to a future phase.

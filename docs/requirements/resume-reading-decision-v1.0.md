# Resume Reading Decision v1.0

**Status:** Approved
**Date:** 7 September 2026

## Decision
Phase 1 will automatically save **one latest Quran reading position**.

## Reading Experience — Visual Marker
While reading the Quran, the application will clearly indicate the last saved position with a subtle **Last Read / Resume marker** beside or near the relevant Ayah.

## Audio Experience — Resume Button
For Quran audio, the application will provide a **Resume** action so the user can continue listening from the last saved position.

## Position Data
The application should retain the relevant chapter (Surah) and verse (Ayah), with exact technical behaviour defined during Functional Requirements and audio design.

## Principles
- Fully offline
- No login/account
- Automatic saving
- Simple and user-friendly
- One latest position only in Phase 1

Multiple manual bookmarks are deferred to a future phase.

# Settings & User Preferences Functional Requirements v1.0

**Status:** Approved
**Date:** 7 September 2026
**Feature:** Settings & User Preferences
**Phase:** Phase 1
**Operating Mode:** Completely Offline

## Objective
Allow users to personalize the reading experience and manage locally stored preferences and user data without adding unnecessary complexity.

## Functional Requirements
- **FR-SET-01:** Allow users to adjust Arabic Quran text size.
- **FR-SET-02:** Save Arabic text size preference locally.
- **FR-SET-03:** Allow users to adjust English translation text size.
- **FR-SET-04:** Save English text size preference locally.
- **FR-SET-05:** Support Light Theme.
- **FR-SET-06:** Support Dark Theme.
- **FR-SET-07:** Save theme preference locally.
- **FR-SET-08:** Display current saved reading position.
- **FR-SET-09:** Allow users to clear saved reading position.
- **FR-SET-10:** Request confirmation before clearing.
- **FR-SET-11:** Provide Reset App Data.
- **FR-SET-12:** Clearly inform users about affected data.
- **FR-SET-13:** Request confirmation before reset.
- **FR-SET-14:** Reset only user data and preferences.
- **FR-SET-15:** Preserve packaged Quran, Dua and audio content.
- **FR-SET-16:** Settings shall work completely offline.
- **FR-SET-17:** No login/account required.

## Reset Scope
Reset may clear favourites, saved reading/listening positions and display/theme preferences.

Reset shall not delete Quran Arabic text, English translation, Dua content, Quran audio or Dua audio.

## UX Principles
Settings shall remain simple, accessible, clear and offline-first. Arabic readability and text contrast must remain strong in both Light and Dark themes.

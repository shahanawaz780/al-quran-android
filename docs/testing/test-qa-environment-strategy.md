# Test / QA Environment Strategy

## Objective
A dedicated testing environment must exist before production.

## Test Cycle
1. Deploy candidate build to Test/QA.
2. Run AI-assisted tests.
3. Business Owner performs functional/UAT testing.
4. Log defects.
5. Analyse and fix.
6. Redeploy to Test/QA.
7. Retest and regression test.
8. Obtain release approval.
9. Promote to Production.

Detailed test automation tools will be selected during the development/testing architecture phase.
